# weihnachten

Weihnachtstheme fuer Claude Code (Desktop- und Mobile-App): tannengruene Flaechen, kerzenrote Akzente, goldenes Kerzenlicht im Dunkelmodus und ein verschneiter Tannenwald mit blinkenden Lichtern und leise fallendem Schnee als Hintergrund.

Ausprobieren: `claude --plugin-dir /pfad/zu/weihnachten`. Im Terminal und in VS Code aendert sich nichts, das Theme wird nur in den Apps gezeichnet.
